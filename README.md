# Security+ and CySA+ Hands-On Labs

This repository contains hands-on cybersecurity labs aligned with **CompTIA Security+ and CySA+ objectives**.

The labs focus on defensive security practices, system hardening, detection engineering, log analysis, threat hunting, and incident response using virtualized lab environments.

---

## Objectives

- Reinforce Security+ and CySA+ concepts through practical labs
- Gain experience with common security tools and workflows
- Practice analysis, detection, and response techniques
- Build a documented cybersecurity lab portfolio

---

## Lab Categories

### Security+ Focused Labs
- Windows system hardening and auditing
- Linux server hardening and secure SSH configuration
- Network segmentation and firewall policy enforcement
- Identity and access management fundamentals

### CySA+ / SOC-Oriented Labs
- Vulnerability assessment and risk prioritization
- SIEM log ingestion and detection engineering
- Network traffic analysis and IOC extraction
- Threat hunting with MITRE ATT&CK mapping
- Incident response evidence collection and tabletop exercises

### Cloud Security Lab
- Secure AWS VPC architecture with logging and monitoring
